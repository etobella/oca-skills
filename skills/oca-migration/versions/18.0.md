# Migrating to 18.0

The module comes from 17.0. Apply the rules of the `oca-guidelines` skill for
18.0. What is specific to this migration:

- **`tree` to `list`.** Odoo provides a script that does most of the work.
  Have a minimal local Odoo installation and run:

  ```
  <path_to_odoo>/odoo-bin --addons-path=${YOUR_PROJECT} upgrade_code --script 17.5-01-tree-to-list.py
  ```

  The change is described in odoo/odoo#159909. Keep the XML ids that have
  `tree` in their name. The context key that selects a list view changes
  from `tree_view_ref` to `list_view_ref`: the script does not cover it, so
  search for it.
- **Company-dependent fields.** If the module has any, a migration script is
  required for the OpenUpgrade path. There is an example in
  OCA/sale-workflow#3958.

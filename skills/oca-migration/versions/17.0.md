# Migrating to 17.0

The module comes from 16.0. Apply the rules of the `oca-guidelines` skill for
17.0. What is specific to this migration:

- **`attrs` and `states` in views.** The OCA module `views_migration_17`
  (repository `server-tools`, branch 17.0) helps to convert them to the
  Python expressions of `invisible`, `required` and `readonly`, in a mostly
  automatic way. Review what it produces.
- **Earlier versions.** If the module comes from a version lower than 16.0,
  do the tasks of the guides in between.

# Migrating to 20.0

The module comes from 19.0. Apply the rules of the `oca-guidelines` skill for
20.0. What is specific to this migration:

- **Access rows and record rules.** Merge the access rows of
  `ir.model.access.csv` and the record rules of the XML files into the new
  model `ir.access`, usually loaded from `security/ir.access.csv`. The
  conversion examples are in odoo/odoo#166359, and Odoo provides a script that
  does most of the conversion (linked from the OCA guide to 20.0).
- **Icons.** Convert the Font Awesome icons declared with `class="fa-..."` to
  the Material Design ones, following the Odoo guide. A tool does most of the
  change (linked from the OCA guide to 20.0).
- **Tests with `BaseCommon`.** Run them. They now use a plain internal user
  with no extra permissions by default. If they fail for permissions, add
  `_test_user_groups = None` to the test class to run them as before, as the
  superuser (`uid=1`). The alternative is to list the groups they need, with
  side effects that depend on the modules loaded.

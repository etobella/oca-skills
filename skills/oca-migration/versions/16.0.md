# Migrating to 16.0

The module comes from 15.0. Apply the rules of the `oca-guidelines` skill for
16.0. What is specific to this migration:

- **Bootstrap 5.** Odoo now uses Bootstrap 5, so the reports, QWeb templates
  and website elements that use Bootstrap 4 elements must be adapted. The
  method `convert_string_bootstrap_4to5` of `openupgradelib` (module
  `openupgrade_160`) converts an HTML fragment given as a string, and does
  most of the work.
- **Maturity level.** Check whether the maturity level of the module can be
  improved in this version. The levels are described in
  <https://github.com/OCA/odoo-community.org/blob/master/website/Contribution/oca_module_lifecycle_development_status.rst>.

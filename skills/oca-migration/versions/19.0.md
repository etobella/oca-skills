# Migrating to 19.0

The module comes from 18.0. Apply the rules of the `oca-guidelines` skill for
19.0. What is specific to this migration:

- **Tests that rely on demo data.** Demo data is not installed by default for
  tests any more. Create the data in the tests themselves.
- **`odoo-test-helper`.** If a test loads a fake model with `FakeModelLoader`
  (from `odoo_test_helper`), look for `FakeModelLoader`, `backup_registry()`,
  `update_registry(...)` and `restore_registry()` and replace them with the
  native way of the 19.0 rules. The `tearDownClass` that only restored the
  registry is no longer needed.
- **Earlier versions.** If the module comes from a version lower than 18.0,
  do the tasks of the guides in between.
